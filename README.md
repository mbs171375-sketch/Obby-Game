🏃‍♂️ Roblox Obby Project
This repository contains a custom-built Roblox Obby (Obstacle Course) designed in Roblox Studio to challenge player agility, timing, and memory. The game features dynamic horizontal and vertical layouts, a seamless checkpoint system to save user progress, and a distinct mix of visible and hidden hazards that keep the platforming experience engaging and unpredictable.

The course utilizes several custom mechanics to test player skills. Bright red Lava Blocks act as instant-kill hazards using a standard Luau health script, while Bounce Pads launch characters upward to clear massive gaps. Additionally, directional Side Accelerators use horizontal velocity to push players sideways mid-jump, and deceptive Invisible Gaps feature solid-looking paths with CanCollide turned off to create trick pitfalls.

To open and edit this project locally, simply clone or download this repository, launch Roblox Studio, and select File > Open from file... to load the .rbxl file. You can immediately playtest the mechanics or expand the course layouts by pressing F5 to start the simulation. Future updates plan to introduce a global speedrun leaderboard and a custom reward collection system.
